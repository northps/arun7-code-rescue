# โค้ดกู้ยาน อรุณ-7 — เอกสารออกแบบเกม

เกม 3D สอนเขียนโปรแกรม Arduino C/C++ ตั้งแต่ศูนย์ ใช้คู่กับบทเรียนใน `02_programming` (P00–P08) และ `01_robot` (R01–R12) ผู้เล่นต้อง **เขียนโค้ดจริง** เพื่อแก้สถานการณ์ในแต่ละด่าน

สถานะ: **องก์ 1–5 (33 ด่าน 92 โจทย์) เล่นได้จริง** · องก์ 6–7 ออกแบบไว้ในเอกสารนี้ และแสดงในแผนที่เป็นด่านล็อก

---

## 1. แนวคิดหลัก

| หัวข้อ | สิ่งที่เลือก |
| --- | --- |
| ผู้เล่น | นักเรียน ม.6 ไม่เคยเขียนโปรแกรม เล่นบนมือถือแนวตั้ง แท็บเล็ต หรือโน้ตบุ๊ก |
| แก่นของเกม | อุปกรณ์ทุกชิ้นในฉาก 3D (ประตู ไฟ หุ่น ป้อมปืน ยานกู้ชีพ) ทำงานตามโปรแกรม Arduino สั้น ๆ ผู้เล่นแก้หรือเขียนโค้ด กด **รัน** โค้ดทำงานทีละบรรทัด บรรทัดที่กำลังทำถูกไฮไลต์ และโลก 3D ตอบสนองทันที |
| เมื่อโค้ดผิด | เกิดผลในโลกเกม (บิตชนผนัง สัญญาณเตือนดัง เอเลี่ยนบุกเข้ามา) พร้อมคำอธิบายภาษาไทย และข้อความ error ภาษาอังกฤษแบบเดียวกับ Arduino IDE (หัวข้อ 15 ของคู่มือ) |
| หนึ่งด่าน = หนึ่งเรื่องใหม่ | บัตรบทเรียน 1 หน้าจอ → โจทย์ 3 ข้อ ยากขึ้นตามลำดับ → ดาว 1–3 ดวง |
| ภาษา | ข้อความทั้งหมดเป็นไทย คำสั่งในโค้ดเป็นอังกฤษตามจริง |
| เกมต้นฉบับ | เนื้อเรื่อง ตัวละคร ฉาก และกลไกออกแบบขึ้นใหม่ทั้งหมด ไม่ได้ลอกเกมใด |

### ตัวละครและโลก

- **ผู้เล่น** — ช่างฝึกหัดบนยานสำรวจ *อรุณ-7* มีบอร์ดควบคุมพกพา (บอร์ดแบบเดียวกับ Arduino UNO) เสียบสั่งอุปกรณ์บนยานได้
- **บิต (BIT)** — หุ่นซ่อมบำรุงตัวเล็ก ทำตามคำสั่ง **ตามตัวอักษรเท่านั้น** (เหมือนกิจกรรม "หุ่นยนต์ครู" ในบท P01) คำสั่งกำกวมหรือสะกดผิด บิตจะตอบว่า "ไม่เข้าใจ"
- **ชาวเคลธ (Kleth)** — เอเลี่ยนที่บุกขึ้นยาน ปิดระบบอัตโนมัติของยานทั้งลำ อุปกรณ์จึงต้องสั่งด้วยโปรแกรมที่เขียนมือ
- **ดาวเวฬา** — ดาวเคราะห์ใต้ยาน ที่ยานกู้ชีพจะลงจอด

### รูปแบบโจทย์ (เรียงจากง่ายไปยาก)

| ชนิด | ผู้เล่นทำอะไร | ใช้เมื่อ |
| --- | --- | --- |
| `blank` เติมช่องว่าง | แตะช่องว่างในโค้ด แล้วแตะชิ้นคำสั่งที่ถูก | เจอไวยากรณ์ใหม่ครั้งแรก |
| `order` เรียงบรรทัด | แตะบรรทัดแล้วเลื่อนขึ้น/ลงให้ลำดับถูก | เรื่องลำดับการทำงาน |
| `fix` หาที่ผิด | รันให้เห็น error ก่อน แตะบรรทัดที่สงสัย แล้วเลือกบรรทัดที่ถูกมาแทน | ฝึกอ่าน error และจับบั๊กที่พบบ่อย |
| `type` พิมพ์โค้ดเอง | พิมพ์โค้ดจริง บนมือถือมีแถบปุ่มสัญลักษณ์ (`;` `{ }` `( )` `==` …) เหนือคีย์บอร์ด | ข้อสุดท้ายของด่าน และด่านช่วงหลัง |

ทุกชนิดตัดสินผลด้วยวิธีเดียวกัน: **เอาโค้ดที่ได้ไปรันจริง** ในตัวแปลภาษา แล้วดูว่าโลกเกมถึงเป้าหมายไหม จึงไม่มี "คำตอบเดียวที่ถูก" โค้ดแบบไหนก็ได้ที่ทำให้สถานการณ์ผ่าน ถือว่าผ่าน หลายข้อรันซ้ำกับ **หลายกรณี** (ค่าเซนเซอร์ต่างกัน) เพื่อกันการใส่คำตอบตายตัว

### ดาว

- ★★★ ผ่านตั้งแต่รันครั้งแรก ไม่ใช้คำใบ้
- ★★ รันพลาดไม่เกิน 2 ครั้ง หรือใช้คำใบ้
- ★ ผ่านได้ในที่สุด

ดาวของด่าน = ค่าต่ำสุดของดาวในโจทย์ของด่านนั้น เก็บใน `localStorage` ผ่านด่านหนึ่งแล้วด่านถัดไปจึงเปิด

| --- | --- | --- | --- | --- |
| 1 | ยานถูกบุก | ชาวเคลธบุกขึ้นยานกลางดึก ผู้เล่นกับบิตต้องฝ่าจากห้องพักไปถึงโรงเก็บยาน | โครงสร้างโปรแกรม ลำดับ Serial ตัวแปร ชนิดข้อมูล `const` การคำนวณ รับค่า `if / else` | P01–P04 (คู่มือ 1–7) |
| 2 | สู้กลับ | ยานกู้ชีพในโรงเก็บยานถูกเคลธล้อมไว้ ผู้เล่นเปิดป้อมปืนและโดรนของยานขึ้นมาสู้ | `switch / case` `for` `while` `do…while` `break` `continue` ลูปซ้อน | P04–P05 (คู่มือ 8–9) |
| 3 | หนีลงดาว | ปล่อยยานกู้ชีพ ฝ่าชั้นบรรยากาศ ลงจอดบนดาวเวฬา ขั้นตอนลงจอดซ้ำกันหลายครั้งจึงต้องจัดเป็นฟังก์ชัน | ฟังก์ชัน `void` parameter `return` ฟังก์ชัน `bool` ตัวแปร local / global | P06 (คู่มือ 10–11) |
| 4 | ผจญภัยบนดาว | สำรวจซากสถานีเก่า เก็บตัวอย่าง ถอดสัญญาณของชาวเคลธ | อาร์เรย์ หาผลรวม ค่ามากสุด-น้อยสุด `String` `char` เกมทายรหัส วิธีหาบั๊ก 5 ขั้น | P07–P08 (คู่มือ 12–13) |
| 5 | หลบนักล่า | ชาวเคลธส่งนักล่าลงมาตาม บิตได้ล้อและเซนเซอร์ใหม่ ต้องขับหลบในหุบเขาและถ้ำ | มอเตอร์ `setMotor` ฟังก์ชันเดิน/เลี้ยว ลูปวิ่งเป็นรูปทรง `readDistance()` หยุดก่อนชน หลบสิ่งกีดขวาง `map` `constrain` | R03–R07 (คู่มือ 14) |
| 6 | หาทางกลับขึ้นไป | ซ่อมกระสวยเก่าในสถานี ตั้งโปรแกรมนำร่องอัตโนมัติ แล้วบังคับจากระยะไกล | state machine: `enum` + `switch` + `millis()` แทน `delay` รับคำสั่งทาง Serial ระบบกันชน | R08–R10 |
| 7 | ศึกสุดท้าย | กลับขึ้นยานอรุณ-7 ยึดห้องเครื่องคืน ปิดประตูมิติของชาวเคลธ | รวมทุกเรื่อง ออกแบบโปรแกรมเองทั้งชิ้น ทดสอบ แก้บั๊ก | R11–R12 |

## 3. รายการด่านทั้งเกม

คำย่อชนิดโจทย์: **ต** = เติมช่องว่าง · **ร** = เรียงบรรทัด · **ผ** = หาที่ผิด · **พ** = พิมพ์เอง

### องก์ 1 — ยานถูกบุก (สร้างแล้ว เล่นได้)

| ด่าน | ชื่อ | เหตุการณ์ | เรื่องที่สอน | โจทย์ |
| --- | --- | --- | --- | --- |
| 1-1 | ตื่นกลางสัญญาณเตือน | ติดอยู่ในห้องพัก ต้องสั่งบิตไปเหยียบแผ่นเปิดประตู | `setup()` / `loop()`, `;`, `{ }`, ลำดับ, ตัวพิมพ์เล็ก-ใหญ่ | ร ผ ผ |
| 1-2 | ส่งสัญญาณขอความช่วยเหลือ | ห้องสื่อสารยังมีไฟ ส่งข้อความออกไปก่อนถูกตัดสัญญาณ | `Serial.begin`, `print` กับ `println`, ข้อความใน `" "` | ต ต ผ |
| 1-3 | รหัสประตูห้องเก็บของ | ประตูมีแป้นรหัส รหัสเปลี่ยนตามกติกาที่เขียนไว้ข้างฝา | ตัวแปร `int`: ประกาศ ใส่ค่า เปลี่ยนค่า, `=` คือ "ใส่กล่อง" | ต ผ พ |
| 1-4 | ห้องปรับความดัน | ต้องตั้งค่าห้องปรับความดันให้ถูกก่อนผ่าน | `float` `bool` `char` `String` `long`, `int` ตัดทศนิยม และ `int` ล้น | ต ผ พ |
| 1-5 | ทางเดินมืด | ไฟดับทั้งทางเดิน ต้องจ่ายไฟผ่านขาของบอร์ด | `const`, ชื่อตัวพิมพ์ใหญ่, `pinMode`, `digitalWrite`, `delay` | ต ผ พ |
| 1-6 | แบ่งพลังงาน | เซลล์พลังงานเหลือน้อย ต้องคำนวณให้พอดี | `+ - * / %`, หารจำนวนเต็ม, `(float)`, ลำดับการคำนวณ | ต ผ พ |
| 1-7 | เสียงจากวิทยุ | ลูกเรือที่ซ่อนอยู่ส่งตัวเลขมาทางวิทยุ ต้องรับค่าแล้วคำนวณรหัสลิฟต์ | `readNumber()`, `++`, `+=`, `-=`, `*=` | ต ร พ |
| 1-8 | หลังประตูมีอะไร | เครื่องสแกนบอกจำนวนเคลธหลังประตู เปิดผิดจังหวะคือจบ | `==` `!=` `<` `>`, `if`, กับดัก `=` กับ `==`, `if (...);` | ต ผ พ |
| 1-9 | ประตูโรงเก็บยาน | ด่านท้ายองก์: ตัดสินใจหลายทางเพื่อเปิดประตูบานสุดท้าย แล้วพบว่ายานกู้ชีพถูกล้อม | `if / else if / else`, ลำดับเงื่อนไข, `&&` `\|\|` | ต ต พ |

ตัวอย่างคำตอบ (โค้ดจริงที่ผ่านด่าน ชุดทดสอบ `tests/levels.test.ts` รันคำตอบทุกข้อ):

```cpp
// 1-1 เรียงลำดับคำสั่ง
void setup() {
  forward();
  forward();
  turnLeft();
  forward();
}
void loop() {
}

// 1-2 print กับ println
void setup() {
  Serial.begin(9600);
  Serial.print("SHIP: ");
  Serial.println("ARUN-7");
  Serial.println("KLETH ON BOARD");
}

// 1-3 ตัวแปร
void setup() {
  int code = 1500;
  code = code + 250;
  enterCode(code);
}

// 1-4 ชนิดข้อมูล
void setup() {
  float pressure = 0.8;
  bool sealed = false;
  setAirlock(pressure, sealed, 'C');
}

// 1-5 ค่าคงที่และขาของบอร์ด
const int LAMP_PIN = 13;
const int LOCK_PIN = 7;
void setup() {
  pinMode(LAMP_PIN, OUTPUT);
  pinMode(LOCK_PIN, OUTPUT);
  digitalWrite(LAMP_PIN, HIGH);
  delay(1000);
  digitalWrite(LOCK_PIN, HIGH);
}

// 1-6 หารและเศษ
void setup() {
  int t = readTimer();
  setClock(t / 60, t % 60);
}

// 1-7 รับค่าและเขียนย่อ
void setup() {
  long n = readNumber();
  n *= 2;
  n -= 3;
  enterCode(n);
}

// 1-8 if
void setup() {
  pinMode(13, OUTPUT);
  int aliens = scanAliens();
  if (aliens > 0) {
    digitalWrite(13, HIGH);
  }
  if (aliens == 0) {
    openDoor();
  }
}

// 1-9 if / else กับ &&
void setup() {
  int aliens = scanAliens();
  int power = readPower();
  if (aliens == 0 && power >= 50) {
    openDoor();
  } else {
    lockDoor();
  }
}
```

### องก์ 2 — สู้กลับ (สร้างแล้ว เล่นได้)

| ด่าน | ชื่อ | เหตุการณ์ | เรื่องที่สอน | โจทย์ | ตัวอย่างคำตอบ |
| --- | --- | --- | --- | --- | --- |
| 2-1 | แผงควบคุมป้อมปืน | ป้อมปืนรับคำสั่งเป็นตัวอักษร `'F'` ยิง `'L'` `'R'` หัน | `switch / case / default`, `char` | ต ผ พ | `switch (cmd) { case 'F': fire(); break; case 'L': aimLeft(); break; default: standby(); break; }` |
| 2-2 | ลืม break | ป้อมปืนหันแล้วยิงเองต่อ เพราะคำสั่ง "ไหล" | ลืม `break`, การไหลแบบตั้งใจ (`case 'F': case 'f':`) | ผ ต | เติม `break;` ท้ายทุก case |
| 2-3 | ยิงห้านัด | เคลธ 5 ตัวตั้งแถว กระสุนต้องพอดี | `for` รู้จำนวนรอบ, `i < 5` กับ `i <= 5` | ต ผ พ | `for (int i = 0; i < n; i++) { fire(); }` |
| 2-4 | นับถอยหลัง | ปืนใหญ่ต้องนับถอยหลังและชาร์จก่อนยิง | `for` นับลง, `i += 20`, ใช้ค่า `i` ในลูป | ต พ | `for (int i = 5; i > 0; i--) { Serial.println(i); }` |
| 2-5 | จนกว่าโล่จะแตก | หัวหน้าเคลธมีโล่ ไม่รู้ต้องยิงกี่นัด | `while`, ลูปไม่รู้จบ (เกมจับได้และอธิบาย), ตัวนับ | ต ผ พ | `while (readShield() > 0) { fire(); shots++; }` |
| 2-6 | ลูกเรือในแนวยิง | เคลธเอาลูกเรือมายืนปนในแถว | `do … while`, `continue`, `break` | ต ต พ | `if (i == h) continue; fireAt(i);` |
| 2-7 | เปิดแผงทั้งโถง | ด่านท้ายองก์: เปิดแผงพลังงานเป็นตารางแล้วยิงนัดสุดท้าย | ลูปซ้อนลูป | ต พ | `for (int r = 0; r < 2; r++) { for (int c = 0; c < 5; c++) { powerCell(r, c); } }` |

### องก์ 3 — หนีลงดาว (สร้างแล้ว เล่นได้)

ฉาก: ห้องโดยสารของยานกู้ชีพ กลางห้องมีภาพจำลองของยานลอยอยู่ แสดงแขนยึด เปลวเครื่องยนต์ ร่ม และขาตั้งตามที่โค้ดสั่ง

| ด่าน | ชื่อ | เหตุการณ์ | เรื่องที่สอน | โจทย์ | ตัวอย่างคำตอบ |
| --- | --- | --- | --- | --- | --- |
| 3-1 | ขั้นตอนปล่อยยาน | แขนยึด 3 ตัว แต่ละตัวต้องปลดล็อกแล้วปล่อย | ฟังก์ชัน `void` ไม่รับค่า, เรียกต้องมี `()`, ชื่อต้องตรง | ต ผ พ | `void freeClamp() { unlockClamp(); releaseClamp(); }` |
| 3-2 | จุดเครื่องยนต์กี่วินาที | เร่งหนีเป็นช่วง ๆ นานไม่เท่ากัน | parameter, `too few / too many arguments` | ต ผ พ | `void burn(int sec) { engineOn(); delay(sec * 1000); engineOff(); }` |
| 3-3 | คำนวณมุมลงจอด | คอมพิวเตอร์นำร่องดับ ต้องคำนวณเอง | `return`, พิมพ์ไม่ใช่คืนค่า, ค่าที่คืนต้องเอาไปใช้ | ต ผ พ | `int biggest(int a, int b) { if (a > b) { return a; } return b; }` |
| 3-4 | ปลอดภัยไหม | ร่มมีผืนเดียว กางผิดความสูงร่มขาด | ฟังก์ชัน `bool`, ใช้ใน `if`, `!` | ต พ | `bool isSafe(int h) { return h > 500 && h < 3000; }` |
| 3-5 | นับรอบสแกน | ตัวนับรอบหายทุกรอบของ `loop()` (ด่านท้ายองก์: ลงจอด) | local / global, การบังชื่อ, `was not declared in this scope` | ผ ผ พ | ย้าย `int scan = 0;` ออกนอก `loop()` |

### องก์ 4 — ผจญภัยบนดาว (สร้างแล้ว เล่นได้)

ฉาก: ซากสถานีสำรวจบนดาวเวฬา (`theme: 'planet'`) มีชั้นวางที่แสดงช่องของอาร์เรย์: ช่องที่โค้ดอ่านเด้งเป็นสีเขียว ช่องที่เขียนเป็นสีส้ม อ่านเกินช่องสุดท้ายมีกรอบแดงกะพริบพร้อมข้อความ "ไม่มีช่อง [5]!"

| ด่าน | ชื่อ | เหตุการณ์ | เรื่องที่สอน | โจทย์ | ตัวอย่างคำตอบ |
| --- | --- | --- | --- | --- | --- |
| 4-1 | ตู้เก็บตัวอย่าง 5 ช่อง | อ่านและแก้ค่าหินตัวอย่าง | อาร์เรย์, index เริ่มที่ 0, ช่องสุดท้ายคือ ขนาด − 1 | ต ผ พ | `int rock[5] = {72, 85, 64, 90, 58}; rock[2] = 70;` |
| 4-2 | อ่านทุกช่อง | รวมพลังงานจากแผงโซลาร์ | `for` กับอาร์เรย์, `i <= 5` อ่านเกินช่อง, `+=` กับ `=`, ไล่ถอยหลัง | ต ผ พ | `for (int i = 0; i < 5; i++) { total += panel[i]; }` |
| 4-3 | จุดที่ร้อนที่สุด | หาปล่องความร้อนที่แรงสุด | ค่ามากสุด, ตำแหน่งของค่ามากสุด, `best = t[0]` ไม่ใช่ 0, `(float)total / n` | ต พ พ | `if (t[i] > best) { best = t[i]; bestIndex = i; }` |
| 4-4 | ถอดสัญญาณเคลธ | สัญญาณเป็นข้อความ | `String`, `length()`, `charAt()`, ต่อข้อความ, `String(n)` | ต ผ พ | `warn("HUNTERS:" + String(count));` |
| 4-5 | ทายรหัสคลัง | คลังบอกแค่ "มากไป / น้อยไป" และลองได้จำกัดครั้ง | เกมทายเลข (P08): `while` + `if`, ค้นแบบแบ่งครึ่ง | ต ต พ | `mid = (lo + hi) / 2;` แล้ว `hi = mid - 1;` หรือ `lo = mid + 1;` |
| 4-6 | บั๊กในเครื่องกำเนิดไฟ | โค้ดเก่ามีบั๊กซ่อนอยู่ (ด่านท้ายองก์) | หาบั๊ก 5 ขั้น: `=` กับ `==`, อ่านเกินช่อง, ขอบเขต, `int` ล้น, หารจำนวนเต็ม | ผ ผ พ | แก้ `int worstIndex = 0` (ขาด `;`), `i <= 5`, `worstIndex = v[i]` |

ต่างจากแบบเดิม: 4-5 เพิ่มโจทย์เติมช่องว่าง 2 ข้อก่อนข้อพิมพ์เอง (ไล่ทีละเลข แล้วค่อยแบ่งครึ่ง) และโปรแกรมเป็นฝ่ายทายด้วย `tryCode(n)` แทนการรับค่าจากคีย์บอร์ด

### องก์ 5 — หลบนักล่า (สร้างแล้ว เล่นได้)

ฉาก: หุบเขาและถ้ำบนดาวเวฬา บิตขับด้วยมอเตอร์จริง (`drive: {}`): ตำแหน่งและมุมเป็นค่าต่อเนื่อง รถเคลื่อนที่ระหว่าง `delay` ตามความเร็วล้อ ชนสิ่งกีดขวางแล้วโปรแกรมหยุด `readDistance()` วัดระยะจริงจากหน้ารถและแสดงเป็นลำแสงในฉาก

กติกาของตัวจำลอง: ความเร็ว 150 ทั้งสองล้อ = 1 ช่องต่อ 500 ms · `setMotor(150, -150)` = หมุนขวา 90° ใน 300 ms · 1 ช่อง = 80 ซม.

| ด่าน | ชื่อ | เหตุการณ์ | เรื่องที่สอน | โจทย์ | ตัวอย่างคำตอบ |
| --- | --- | --- | --- | --- | --- |
| 5-1 | ใส่ล้อให้บิต | ชุดนำทางไหม้ ต้องสั่งล้อเอง | `setMotor(left, right)`, เขียน `forward()` `backward()` `stopCar()` เอง, ลืมสั่งหยุด | ต ผ พ | `void forward() { setMotor(150, 150); }` |
| 5-2 | เลี้ยวให้ได้มุม | เลี้ยว 90° ด้วยเวลา | `turnLeft()` `turnRight()`, ค่าคงที่ `TURN_MS` | ต ผ พ | `void turnLeft() { setMotor(-150, 150); delay(TURN_MS); stopCar(); }` |
| 5-3 | วิ่งรอบค่าย | ลาดตระเวนผ่านธงทุกมุม | ลูปกับฟังก์ชัน (R04), สี่เหลี่ยมจัตุรัสและผืนผ้า | ร พ | `for (int i = 0; i < 4; i++) { forward(); delay(1000); turnRight(); }` |
| 5-4 | ตาของบิต | ติดเซนเซอร์วัดระยะ | `readDistance()`, พิมพ์ค่าออก Serial, เฉลี่ยค่าที่กระตุก | ต ผ พ | `total += readDistance();` แล้ว `return total / 5;` |
| 5-5 | หยุดก่อนชนผา | วิ่งตรงแล้วหยุดเอง | `if / else` ใน `loop()` กับเซนเซอร์ (R06), `DANGER_CM`, `delay` ยาวทำให้รถตาบอด | ต ผ พ | `if (d < DANGER_CM) { stopCar(); } else { forward(); }` |
| 5-6 | เขาวงกตถ้ำ | นักล่าตามมา ต้องหลบสิ่งกีดขวางเอง (ด่านท้ายองก์) | หันไปวัดซ้าย-ขวาแล้วเลือกทางโล่ง (R07 แบบหันทั้งตัว) | ต พ | `if (left > right) { turnLeft(); turnLeft(); }` |

ต่างจากแบบเดิม: 5-5 เปลี่ยนชื่อจาก "หยุดก่อนตกเหว" เป็น "หยุดก่อนชนผา" เพราะเซนเซอร์อัลตราโซนิกมองไม่เห็นเหว · 5-6 ไม่ได้สอน `map` กับ `constrain` · 5-3 ไม่มีรูปหลายเหลี่ยม `360 / sides`

### องก์ 6 — หาทางกลับขึ้นไป

| ด่าน | ชื่อ | เหตุการณ์ | เรื่องที่สอน | โจทย์ | ตัวอย่างคำตอบ |
| --- | --- | --- | --- | --- | --- |
| 6-1 | ตั้งชื่อสถานะ | กระสวยมี 4 โหมด | `enum State { CRUISE, BACKUP, SCAN, TURN };` | ต ผ | `State state = CRUISE;` |

### 4.1 เครื่องมือ

- **Vite + TypeScript + three.js** ไม่มี framework หน้าจอ (DOM ธรรมดา) เพื่อให้เบาบนมือถือ

### 4.3 ตัวแปลภาษา

รองรับ:

- ชนิด `int` (16 บิตเหมือน UNO: 32767 + 1 = −32768) `long` `unsigned long` `byte` `float` `bool` `char` `String`, `const`, `#define`, `enum`
- ตัวดำเนินการทั้งหมดในคู่มือหัวข้อ 5 รวม `(float)` และ `?:`; จำนวนเต็มหารกันเศษทิ้ง
- `if / else if / else`, `switch / case / default` (ไหลเมื่อไม่มี `break`), `for`, `while`, `do … while`, `break`, `continue`
- ฟังก์ชันที่ผู้เล่นเขียนเอง (parameter, `return`, เรียกซ้อน, เรียกก่อนประกาศได้เหมือน Arduino IDE), ขอบเขตตัวแปรตาม `{ }`
- อาร์เรย์ 1 มิติ, `String`: `+`, `length()`, `charAt()`, `[i]`, `toInt()`, `toUpperCase()`, `String(n)`
- คำสั่ง Arduino: `Serial.begin/print/println`, `delay`, `millis`, `pinMode`, `digitalWrite`, `digitalRead`, `analogWrite`, `analogRead`, `abs`, `min`, `max`, `constrain`, `map`, `random`, `pow`, `sqrt`
- คำสั่งของเกม ที่ด่านกำหนด เช่น `forward()`, `turnLeft()`, `openDoor()`, `readDistance()`, `fire()`, `readNumber()`

การทำงาน: `runProgram(โค้ด, host)` → ตัดคำ → แยกโครงสร้าง → ตรวจ → รัน `setup()` หนึ่งครั้ง แล้ว `loop()` ตามจำนวนรอบที่ด่านกำหนด ผลที่ได้คือ **trace**: รายการขั้น `{บรรทัด, เหตุการณ์ในโลก, ข้อความ Serial, ค่าตัวแปร}` หน้าจอเล่น trace ทีละขั้น จึงไฮไลต์บรรทัดและขยับฉาก 3D ได้ตรงกัน

**จำกัดจำนวนขั้น** (ค่าเริ่มต้น 4,000 คำสั่ง): เกินแล้วหยุดและอธิบายว่าเป็นลูปไม่รู้จบ

ข้อผิดพลาดที่ตรวจและอธิบายเป็นไทย (ตรงกับคู่มือหัวข้อ 15):

| ชนิด | ข้อความแบบคอมไพเลอร์ | สอนในด่าน |
| --- | --- | --- |
| ขาด `;` | `expected ';' before '…'` | 1-1 |
| `{ }` ไม่ครบ | `expected '}' at end of input` | 1-1 |
| ชื่อไม่รู้จัก / ตัวพิมพ์ผิด | `'…' was not declared in this scope` + `did you mean '…'?` | 1-1, 1-3 |
| ข้อความไม่ปิด | `missing terminating " character` | 1-2 |
| ภาษาไทยนอกข้อความ | `stray '\340' in program` | ทุกด่านที่พิมพ์เอง |
| ประกาศซ้ำ | `redeclaration of 'int x'` | 1-3 |
| `char c = "A";` | `invalid conversion from 'const char*' to 'char'` | 1-4 |
| แก้ค่าคงที่ | `assignment of read-only variable '…'` | 1-5 |
| argument ไม่ครบ / เกิน | `too few / too many arguments to function '…'` | 1-4, องก์ 3 |
| `5 = x` | `lvalue required as left operand of assignment` | 1-8 |
| `else` ลอย | `'else' without a previous 'if'` | 1-9 |
| ไม่มี `setup` / `loop` | `undefined reference to 'setup'` | 1-1 |

สิ่งที่คอมไพเลอร์จริง **ไม่เตือน** แต่เกมเตือนหลังรันพลาด (เรียกว่า "ข้อสังเกต"): `if (x = 5)`, `if (...);`, `int` ล้น, ใส่ทศนิยมลง `int`, หารจำนวนเต็มแล้วเก็บใน `float`, หารด้วยศูนย์, อ่านอาร์เรย์เกินช่อง, ลืม `Serial.begin`, ลืม `pinMode`, เรียกฟังก์ชันลืม `()`, ลูปไม่รู้จบ

### 4.4 โลกจำลองและการตัดสิน

- ด่านบรรยายห้องเป็นตารางตัวอักษร (`#` ผนัง, `.` พื้น, `B` บิต, `D` ประตู, `P` แผ่นเหยียบ, `A` เคลธ, `T` แผงควบคุม, `L` โคมไฟ, `G` ยานกู้ชีพ, `U` ป้อมปืน)
- คำสั่งของเกมเปลี่ยนสถานะโลกและส่ง "เหตุการณ์" ให้ฉาก 3D เช่น `move`, `bump`, `door`, `lamp`, `panel`, `sense`, `rush`
- เป้าหมายเป็นข้อมูล: `door: 'open'`, `at: [x, y]`, `serial: "…"`, `pins: {13: 1}`, `set: {enterCode: [1750]}`, `called`, `notCalled`, `targetsLeft: 0` (ยิงเคลธหมดและไม่ยิงเกิน), `gridFull` (เปิดแผงครบตาราง), `clampsLeft: 0` (ปลดแขนยึดครบ), `burns: [2, 4]` (จุดเครื่องยนต์กี่วินาที ตามลำดับ), `calledTimes: {land: 1}` (เรียกกี่ครั้งพอดี), `vaultOpen: true` (ทายรหัสคลังถูกภายในจำนวนครั้งที่กำหนด), `stopped: true` (มอเตอร์หยุดตอนจบ), `flags: true` (ผ่านธงครบ), `frontCm: [8, 25]` (หยุดห่างสิ่งกีดขวางในช่วงนี้)
- ข้อที่มีหลายกรณี รันทุกกรณีแบบเงียบก่อน แล้วเล่นภาพของกรณีแรกที่พลาด (หรือกรณีแรกถ้าผ่านหมด)
